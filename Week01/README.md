# DTS 211 — Week 1

## Getting Started with R and RStudio

### Week 1 Focus

This week introduces students to:

- R programming
- Applications of R in data science
- RStudio
- RStudio Project creation
- The RStudio interface
- Console and Source panes
- Environment, Files, Plots and Packages
- Basic R commands
- Basic data analysis
- Simple data visualisation

### Week 1 Materials

- **Practical Manual:** `DTS211_Week1_Practical_Manual_RStudio.md`
- **RStudio Practical Script:** `DTS211_Week1_Practical_RStudio.R`

### Learning Workflow

> Think → Code → Run → Observe → Correct → Explain

Students should create an RStudio Project for DTS 211 and keep their Week 1 work inside the `Week01` folder.
