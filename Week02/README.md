## Week 2 learning focus

- Evaluation in R
- Assignment and R objects
- Object names
- Numbers and basic computations
- Numeric, character and logical objects
- Attributes and basic structure
- `class()`, `typeof()`, `str()` and `attributes()`
- Reassignment and object inspection

## How to work

1. Read the Week 2 section of the Class Notes.
2. Open the practical manual.
3. Open and run the `.R` script section by section.
4. Predict results before running commands.
5. Complete the independent challenge and assignment.

## Computing environments

You can use either:
- **RStudio Desktop**, with R installed on your computer; or
- **Posit Cloud**, which runs RStudio in a browser.

Both environments can run the same `.R` script.

## Important

The detailed study of vectors, matrices, arrays, lists, factors and data frames is reserved for later weeks. Week 2 introduces object inspection and structure at a foundational level.
